# University of Dukes Website

A responsive university landing page developed using HTML, CSS, and JavaScript.

---

## 📌 Project Description

The **University of Dukes Website** is a modern and responsive educational institution landing page designed to showcase the university’s identity, academic excellence, campus life, and innovation culture.

The website includes:

* A navigation bar for easy access to pages
* A hero section with an interactive image slider
* Feature sections highlighting academics, innovation labs, and campus life
* A footer with social media links
* Responsive design principles for better viewing across devices

This project demonstrates the use of:

* Semantic HTML5 structure
* External CSS styling
* JavaScript integration
* Swiper.js image slider
* Font Awesome icons
* Google Fonts

---

# 🛠 Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and layout
* **JavaScript** – Interactive functionality
* **Swiper.js** – Image slider functionality
* **Font Awesome** – Icons
* **Google Fonts** – Typography
